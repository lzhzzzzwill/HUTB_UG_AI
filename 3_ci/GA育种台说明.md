# GA 育种台 · 交互式三维教学演示

双击 `ga-bench/ga-bench.html` 即可离线打开。全部数据、样式与算法内嵌，无需联网，无需 Python 或任何 3D 库。

`ga-bench/ga-bench-dark.html` 是同一台机器的暗色版（投影仪偏暗或深色背景时使用）。

## 为什么选这个案例

`3_ci` 里有 GA、PSO、PCA、特征选择等内容。其中**遗传算法做 Iris 特征选择**最适合被做成一台"机器"：
它有四个互相独立、动作各异的操作——按适应度抽签、在一点剪断并交换、按位翻转、测量打分——正好对应四个可以画出来的机构；
PSO 的"粒子在 13 维里飞"没有对应的实体动作，勉强画出来只会变成抽象的散点面板。

这台机器被设计成一台**实验台式的育种仪**：一块台面，五个工位，每个工位的机械动作就是算法的一步。

## 工位与概念对照

| 工位 | 机器上的东西 | 对应的算法 | 动画里看到什么 |
|---|---|---|---|
| 左：选种转盘 | 水平圆盘，8 条扇区分隔筋，盘沿一颗钢球 | 轮盘赌选择 | 扇区宽度 = 该个体适应度占总适应度的比例；钢球绕盘滚动，转盘把被抽中的扇区转到钢球下方 |
| 中：种群针板 | 8 个托盘 × 4 根针，每盘一条适应度标尺 | 种群 / 染色体 / 适应度 | 高针 = 1（选中该特征），低针 = 0；标尺柱高 = 该个体的五折准确率；最优个体的托盘描边加亮 |
| 右上：交叉台 | 两条钢带（各 4 个柱钉），中间一把铡刀，可沿横梁移到第 1/2/3 位之后 | 单点交叉 | 铡刀落下、两条钢带的尾段抬起互换；按交叉率决定这一组剪不剪 |
| 前：记录仪 | 纸带 + 龙门笔架 | 适应度进化曲线 | 每完成一代评价，笔在纸带上画出"历史最优"（纸带纵轴 0.94–1.00） |
| 右前：表盘 | 指针表 | 适应度函数 | 指针指向当代历史最优；刻度是 3-近邻分层五折的平均准确率 |

绘图本身是等轴测三维投影：每个零件都是实体、按深度排序、有四个受光面和一条轮廓线；
转盘的扇区、分隔筋和钢球是**绕竖轴真实旋转**的（每帧按新角度重新投影），不是贴图。

## 操作

- **点击画面 / 空格**：走一步。一步 = 选择 → 交叉 → 变异 → 评价 中的下一个动作；一步没走完时再点一次会直接跳到这一步的结束。
- **R**：重置到第 0 代。
- **鼠标悬停**在某个工位上：右下角换成该工位的解释（悬停会暂停自动演示）。
- 没人操作约 2 秒后，它会自动把 6 代跑一遍（"讲解模式"）；跑完停在最终状态，不会自己清空。

## 数字从哪来

图的右下角、表盘、纸带上的每一个数都来自同一份模型：

- 数据是 scikit-learn 的 Iris（150 样本 × 4 特征），内嵌在 `ci_data.json`；
- 适应度 = 3-近邻分类器的**分层五折**平均准确率，不打乱、不标准化，等距时按样本索引、投票并列取最小类别；
- 算法与 `3_teach_ci.ipynb` 一致：种群 8、染色体 4 位、代数 6、交叉率 0.8、变异率 0.15、随机种子 42，选择用轮盘赌，交叉用单点，变异逐位，历史最优只在"初始化"和"变异后评价"时替换（没有精英回插）。

这套实现与 `3_ci/ci_animation.html` 里的 `CI` 模块同源，因此两处动画给出同一串数字：
第 0 代历史最优 **0.9600**，第 1 代升到 **0.9733** 后不再变化（6 代共 7 个点，纸带上是"先抬一步、然后走平"）。

动画里的每个动作也照着模型的记录走：第 1 代第 1/4 组确实是个体 3 × 4 在第 1 位后剪断，第 1 代变异的第 1 处也确实是个体 2 的第 2 位，读出的适应度就是 `afterMutate` 那一代的真实分数。画面不"演"一个近似的过程，它回放的就是这次运行。

## 重新生成

```sh
cd 3_ci/ga-bench
node build.mjs          # ga-bench.html（浅色）
node build.mjs --dark   # ga-bench-dark.html
```

- `model.mjs`：数据 → 交叉验证适应度 → 带完整过程的 GA 运行（每一步的种群、选中编号、交叉点、翻转位、分数都记下来）。
- `build.mjs`：用 anatomy 的等轴测工具包把静态零件画成 SVG，并把 trace 嵌进页面。
- `live.js`：页面里的那一半——按 trace 播放四个动作、重绘会动的零件（针、标尺、钢带、铡刀、指针、纸带）、处理交互与无障碍。

## 已知取舍

- 规则和随机数在浏览器里用同一套线性同余序列重放，因此**数值与 Python 现场运行不会逐位相同**（这一点与 `ci_animation.html` 相同）；但同一随机种子下每次打开都完全一致，便于课堂复述。
- 纸带只画"历史最优"一条线；"当代平均"只出现在右下角读数里（第 3、6 代平均会掉到 0.91，原因是变异把某个子代打成了单特征），需要时可以用 notebook 里的两张曲线图补充。
- 交叉台一次展示一组（4 组依次做），不是四条钢带同时开工；这样机构才看得清。
