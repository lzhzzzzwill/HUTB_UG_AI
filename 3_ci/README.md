# 3_ci — 遗传算法与粒子群算法 · 特征选择

## 教学内容

本实验介绍两种群体智能优化算法在特征选择问题中的应用：

- **遗传算法（Genetic Algorithm, GA）**：模拟生物进化过程（选择、交叉、变异），在鸢尾花（Iris）数据集上搜索最优特征子集。
- **粒子群优化算法（Particle Swarm Optimization, PSO）**：模拟鸟群觅食行为，在葡萄酒（Wine）数据集上搜索最优特征子集。

两种算法均从零实现，仅使用 `numpy`、`random`、`sklearn`，不依赖任何进化算法框架。

### 核心概念

#### 遗传算法

| 生物学概念 | 遗传算法中的对应 | 作用 |
|-----------|-----------------|------|
| 种群 (Population) | 候选解集合 | 搜索的"人群" |
| 染色体 (Chromosome) | 一个候选解（0/1 串） | 表示特征选择方案 |
| 基因 (Gene) | 染色体上的一个位点 | 表示一个特征是否选中 |
| 适应度 (Fitness) | 交叉验证准确率 | 衡量解的好坏 |
| 选择 (Selection) | 轮盘赌选择 | 优胜劣汰 |
| 交叉 (Crossover) | 基因片段交换 | 产生新解 |
| 变异 (Mutation) | 基因位翻转 | 维持多样性 |

- **染色体编码**：二进制向量（1 = 选择该特征，0 = 不选）
- **适应度函数**：使用 KNeighborsClassifier（KNN, k=3）进行 5 折交叉验证，以平均准确率作为适应度值（纯准确率，无特征数惩罚项）
- **选择操作**：轮盘赌选择（Roulette Wheel Selection）；教学中提及锦标赛选择作为概念对比，未实现
- **交叉操作**：单点交叉（Single-Point Crossover）
- **变异操作**：按位翻转（0 变 1，1 变 0）

#### 粒子群算法

| 概念 | 说明 |
|------|------|
| 粒子 (Particle) | 一个候选解（连续位置向量） |
| 速度 (Velocity) | 决定粒子下一次移动的方向和距离 |
| 个体最优 (pBest) | 粒子自身历史最佳位置 |
| 全局最优 (gBest) | 整个种群的历史最佳位置 |

**速度更新公式**：

```
v[i] = w * v[i] + c1 * r1 * (pBest[i] - x[i]) + c2 * r2 * (gBest - x[i])
```

| 项 | 名称 | 含义 |
|----|------|------|
| w * v[i] | 惯性项 | 保持当前飞行方向 |
| c1 * r1 * (pBest - x) | 个体认知项 | 向自身历史最佳移动 |
| c2 * r2 * (gBest - x) | 社会项 | 向全局最佳移动 |

- **连续到离散转换**：位置值 > 0.5 视为选中该特征
- **适应度函数**：与 GA 相同，使用 KNN + 5 折交叉验证准确率

### GA 与 PSO 对比

| 比较维度 | 遗传算法 (GA) | 粒子群算法 (PSO) |
|---------|-------------|-----------------|
| 模拟对象 | 生物进化（自然选择） | 鸟群觅食（群体智能） |
| 核心操作 | 选择、交叉、变异 | 速度更新、位置更新 |
| 信息共享 | 间接（通过种群基因池） | 直接（pBest + gBest 指导） |
| 收敛速度 | 较慢 | 较快 |
| 局部最优 | 较不容易陷入 | 较容易早熟收敛 |
| 参数数量 | 较多（种群大小/交叉率/变异率） | 较少（w/c1/c2） |

## 实验流程

### GA 完整流程

```
初始化种群 → 评价适应度 → 选择（轮盘赌） → 交叉（单点） → 变异 → 评价 → 更新最优 → 循环
```

1. **初始化种群**：随机生成 8 个长度为 4 的二进制染色体，确保每个至少有一个 1
2. **评价**：每个个体用 KNN（k=3）+ 5 折交叉验证计算适应度
3. **选择**：轮盘赌选择，适应度高的个体有更高概率被选中
4. **交叉**：两两配对，以 0.8 概率在随机位置进行单点交叉
5. **变异**：每个基因位以 0.15 概率翻转
6. **精英保留**：若新一代最优优于历史最优，则更新
7. **可视化**：每代输出种群热力图和适应度柱状图，最终绘制适应度进化曲线（全局最优 + 平均适应度）

### PSO 完整流程

```
初始化位置和速度 → 评估 → 设置 pBest 和 gBest → 更新速度和位置 → 评估 → 更新 pBest 和 gBest → 循环
```

1. **初始化**：10 个粒子，位置在 [0, 1] 随机，速度在 [-0.2, 0.2] 随机
2. **评估**：每个粒子位置通过阈值 0.5 转为二值化选择，用 KNN（k=3）+ 5 折交叉验证计算适应度
3. **初始化 pBest/gBest**：初始位置设为 pBest，最优 pBest 设为 gBest
4. **迭代更新**：按速度更新公式更新每个粒子的速度和位置，裁切位置到 [0, 1]
5. **更新最优**：若当前适应度优于 pBest 则更新 pBest，若 pBest 优于 gBest 则更新 gBest
6. **可视化**：每次迭代输出 gBest 适应度和选中特征，绘制收敛曲线和特征数量变化曲线

## 结果分析

### GA 输出

- 每代种群热力图（观察染色体模式演化）
- 每代适应度柱状图（观察个体适应度分布）
- 适应度进化曲线：全局最优适应度与平均适应度随代数的变化
- 最终历史最优解：最优染色体及其对应的特征组合

### PSO 输出

- 每次迭代的 gBest 适应度、二值化表示、选中特征数及特征名称
- 收敛曲线：gBest 适应度随迭代次数的变化
- 特征数量变化曲线：gBest 选中特征数随迭代次数的变化

### 对比实验（仅 PSO, Wine 数据集）

使用全部 13 个特征与 PSO 选中的特征子集，分别用 KNN（k=3）+ 5 折交叉验证对比分类准确率：

- 全部 13 个特征的准确率
- PSO 选中特征的准确率
- PSO 减少的特征数

另提供 PCA 降维可视化，用于观察 PSO 选中特征后不同类别在二维空间中的分布。

## 注意事项

- **从零实现**：GA 和 PSO 均使用 `numpy`、`random`、`sklearn` 从零编写，未使用 `deap` 等进化算法框架。
- **随机性**：遗传算法和粒子群算法均为随机优化算法，每次运行结果可能不同。实验中使用 `RANDOM_SEED=42` 固定随机种子以保证可复现。
- **分类器**：适应度计算仅使用 KNeighborsClassifier（KNN），未使用决策树等其他分类器。
- **适应度函数**：适应度为纯交叉验证准确率，无特征数惩罚项。
- **交叉方式**：仅实现单点交叉（Single-Point Crossover）。
- **选择方式**：实现轮盘赌选择；教学中提及锦标赛选择作为概念对比，未在代码中实现。

#### 为什么又做了一台 GA？

`ci_animation.html` 是数据面板 + 函数曲面的"抽象层面"演示；GA 育种台把 GA 做 Iris 特征选择的流程呈现为一台**实验台式的育种仪**——四个核心操作（选择、交叉、变异、评价）被做成四个可以画出来的"机构"，每个工位的机械动作就是算法的一步。

#### 5 个工位

| 工位 | 机器上的东西 | 对应 notebook 概念 | 动画里看到什么 |
|------|------------|------------------|--------------|
| 🎡 **选种转盘** | 水平圆盘 + 钢球 | 轮盘赌选择 | 扇区宽度 = 该个体适应度占总适应度的比例；钢球绕盘滚动，转盘把被抽中的扇区转到钢球下方 |
| 📊 **种群针板** | 8 个托盘 × 4 根针 + 适应度标尺柱 | 种群 / 染色体 / 适应度 | 高针 = 1（选中该特征），低针 = 0；标尺柱高 = 该个体的 5 折准确率；最优个体的托盘描边加亮 |
| ✂️ **交叉铡刀台** | 两条钢带 + 可移动铡刀 | 单点交叉 | 铡刀落下、两条钢带的尾段抬起互换；按交叉率决定这一组剪不剪 |
| 📈 **记录仪纸带** | 纸带 + 龙门笔架 | 适应度进化曲线 | 每完成一代评价，笔在纸带上画出"历史最优" |
| 🎯 **表盘** | 指针表 | 适应度函数 | 指针指向当代历史最优；刻度是 3-NN 分层五折的平均准确率 |

#### 操作

- **点击 / 空格**：走一步（选择 → 交叉 → 变异 → 评价中的下一个动作）
- **R**：重置到第 0 代
- **悬停工位**：右下角换成该工位的解释（悬停会暂停自动演示）
- **自动讲解**：没人操作约 2 秒后自动把 6 代跑一遍，跑完停住

#### 数字与 notebook 一致

图上每一个数（表盘指针、纸带位置、托盘标尺）都来自同一份模型：

- 数据：scikit-learn Iris（150 样本 × 4 特征），内嵌在 `ci_data.json`
- 适应度：3-NN 分层五折平均准确率（不打乱、不标准化）
- 算法参数：种群 8、染色体 4 位、代数 6、交叉率 0.8、变异率 0.15、种子 42
- 历史最优从 **0.9600** 升到 **0.9733** 后不再变化（6 代 7 个点）

动画回放的是真实运行的每一步：第 1 代第 1/4 组确实是个体 3×4 在第 1 位后剪断，第 1 代变异的第 1 处确实是个体 2 的第 2 位。
