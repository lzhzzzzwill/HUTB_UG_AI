# 育种机 · 用一台台式仪器讲清楚遗传算法

这是一张等轴测（isometric）交互图：把遗传算法做成一台**真实可造**的台式仪器「育种机」，
用它的机构把算法的每一步演示出来。打开 `index.html` 即可（另有浅色版 `index-light.html`）。

```
genetic-algorithm/
├── index.html            深色主题（打开这个）
├── index-light.html      浅色主题，内容相同
├── build.mjs             几何 + 组装 + 页面生成
├── live.mjs              页面里的活体行为（模型、上弦、交互）
├── kit/                  anatomy 的工具包（等轴测投影、实体、表盘、卡片样式）
├── scripts/inline-kit.mjs  把工具包内联进单文件页面
├── see.mjs               调试工具：把生成好的 SVG 线稿光栅化成 ASCII，便于无图环境核对
└── shots/                截图
```

重新生成：

```sh
node build.mjs           # index.html
node build.mjs --light   # index-light.html
```

---

## 一、为什么用这台机器

遗传算法的骨架是：**一群候选解 → 评估适应度 → 选好的当父代 → 交叉 → 变异 → 换代**。
「育种机」把每一环都做成一个能看见的机械动作：

| 算法里的东西 | 机器上的东西 |
| --- | --- |
| 种群（8 个个体） | 条架上的 **8 根基因条**，插在 8 个槽里 |
| 染色体（8 位 0/1） | 每根条上的 **8 个销钉**：抬起 = 1，凹下 = 0 |
| 适应度评估 | 测量头用**弹簧触针**沿销钉扫过；销钉抬起就把触针顶起一次 |
| 适应度数值 | 触针每顶起一次，**棘爪**把**棘轮**推进一齿，表盘**指针**转过 40°；8 个销钉走完，指针读到的就是这条的分数 |
| 选择（保留最优） | 分数最高的两根条**留在槽里**不动，当父代 |
| 复制父代 | 测量头把分数最低的两根夹进夹爪，逐一**压到高分条上**，把图案复制到副本上 |
| 单点交叉 | **模座**滑到选定的**切点**，一刀把两份副本都切断；两台**传送梭**一高一低地把两段尾段交叉换位 |
| 拼接 | 模座回到接缝处压合，接缝留下一道浅缝 |
| 变异 | 冲头滑到某一位，**打掉**这一位（两份副本同时翻同一位） |
| 换代 | 改写好的两条**放回原来的槽位**；其余 6 条不动 |
| 收敛过程 | 右侧**记录仪**：走纸一格一代，笔沿横向按「本代最好分数」移动，画出收敛曲线 |
| 代数 | 记录仪下方的**计数器**窗口 |

一句话：**这台机器把「打分—选优—复制—切断—换尾—压接—变异—回位」这一套动作，做成了一台可以真的造出来的育种机。**
机器上出现的每个数字（分数、切点、变异位、代数、曲线）都来自页面里跑的那个真算法，不是预先摆好的。

## 二、一轮完整的动作（约 11 秒）

机头是一个沿龙门架左右行走的**测量头**，它把整套工序串起来：

1. **逐条测量**：机头停在某一根条上方，模座沿条长方向扫过，触针逐个跳过销钉，
   棘轮"咔"一下、指针跳一格；读数窗口同步显示 `第 n 条 · k/8`。
   八根条依次量完，表盘复位。
2. **取出最差的两条**：机头移到分数最低的两个槽位，夹爪（两片夹指）从两侧夹住条尾的**凸舌**，
   把条提起 7.5，离开条架。
3. **复制父代**：机头移到分数最高的两根条上方，把夹着的副本压到父代上（压 8），
   图案转移；抬起来时，副本上的销钉已经和父代一样。
4. **切断**：夹着两条副本，模座滑到切点（刻度 1–5），四只压脚先压住，刀片落下，
   两份副本在同一位置被切断。
5. **交换尾段**：两台传送梭分别夹住一段尾段，一台升高 9.6 从左跨到右，另一台升 4.6 从右跨到左；
   错开高度，所以只擦身而过、不相撞。
6. **压接**：模座回到接缝，压脚压合，两条新染色体成立（接缝上留一道浅线）。
7. **变异**：模座移到被抽中的那一位，冲头落下，打下这一位。
8. **回位**：机头把两条改写好的条送回原来那两个空槽，落到条面上，松爪。
9. **换行**：走纸一格，笔移到本代最好分数的位置，画上一段；计数器 +1，开始下一代。

## 三、页面里真正的算法（`live.mjs`）

```js
种群 8 条 × 染色体 8 位      fitness = 该条上 1 的个数（0..8）
每一代：
  scores  = 每条求和
  order   = 按分数降序（同分按槽位）
  父代     = order[0], order[1]        // 最好的两条留下
  被改写   = order[6], order[7]        // 最差的两条进夹爪
  cut     = 1 + floor(rand * 5)        // 单点交叉，切在 1..5 之后
  bit     = floor(rand * 8)            // 变异位
  childA  = A[0..cut) + B[cut..)       // A、B 是两份副本
  childB  = B[0..cut) + A[cut..)
  childA[bit] ^= 1; childB[bit] ^= 1   // 冲头同时打两份
  种群[被改写] = childA, childB          // 精英保留 + 最差替换
```

* 正因为是"**改写最差的两条**"，种群规模恒为 8：父代不动，最差的两条被覆盖。
* 切点只能落在 1–5，是因为夹爪要夹住尾段：切点太靠前，尾段就没有地方给传送梭下爪；
  这是机器的物理限制，也写进了算法（`cut ∈ 1..5`）。
* 记录仪窗口显示最近 9 代，旧的曲线向左滑出纸面。

## 四、怎么玩

* **把指针悬停在某根基因条上**：机头会走到那一条上，触针当场扫一遍，表盘读数、角落读数同步给出这条的分数。
* **← →**（或 ↑ ↓）：在八条之间逐条移动；**Home / End** 跳到两端。
* **空格**：开始 / 暂停自动运行（默认打开页面约 1 秒后自动开始，一轮约 11 秒）。
* 指针移开后约 1.6 秒恢复自动运行。
* 尊重 `prefers-reduced-motion`：此时不自动运行，画面停在一帧——机头停在第一根条上，
  表盘指针停在它的真实分数上；悬停和键盘仍然可用。

## 五、图的读法（细节小抄）

* **条架**：底板、9 片隔条（每片两颗螺钉）、两端挡块；条架下方是机座。
* **基因条**：条身、尾部的凸舌（给夹爪咬合）、8 个销钉；抬起的销钉有倒角和高光点，
  凹下的位置是一个凹坑（环线 + 中心点）。
* **测量头**：龙门架双轨（四根立柱、可调顶帽）、滑座、后部表盘外壳、**表盘**（0–8 刻度、
  40° 一格、指针、归零滚花旋钮）、下方夹爪与两副夹指、前部两根立柱、**工具轨**（带 1–5 切点刻度）、
  **模座**（四只压脚、刀片、翅片、传送梭支架）、**冲头**、**触针**（沿模座滑动，弹簧触针头）。
* **记录仪**：机座、纸面（带格线）、前后压纸唇、笔架横轨、笔、计数器窗口（两位数字）。
* **台面**：四角支脚、内凹刻线、四颗螺栓、前缘**钢尺**（4 单位一小格、5 格一大格）、
  名牌板（三道代表印字的短线）、前端**零件盘**（三颗备用销钉）、右侧**计数器**。

配色遵循 anatomy 的规矩：底座与脚 `lo`、结构 `mid`、被解释的主体（基因条）`hi`，
**唯一一个 `lit` 是表盘指针**——观众该盯着看的东西。

## 六、做过哪些核对

* **读数与动作同源**：表盘角度 = 触针"已经扫过的抬起的销钉数"，切点/变异位/代数直接写进 DOM，
  没有另写一套假数据。
* **每一步的状态**：用 Chrome DevTools 协议逐帧抽查（`window.__breeder.state()`），
  确认取出的是 `order[6]/order[7]`、复制的是 `order[0]/order[1]`、
  交换后 `tailAx = +22, tailBx = -22`、回位后槽位内容等于 `childA/childB`。
* **线头检查**：anatomy 的 `scripts/lines.mjs` 会在深色、浅色两版上逐条检查
  「每一根纹理线的端点都要落在某样东西上」，当前两版都是 **0 个悬空端点**。
* **版面**：桌面 1440、手机 390 宽均无横向滚动；控制台无报错、无异常。
* **静态帧**：`prefers-reduced-motion` 下停在一帧诚实的读数上。

## 七、已知的取舍

* 这台机器是**为解释而设计**的仪器，不是某台真实设备的图纸：它的每一个零件都按真实机器的
  做法摆放（每个零件都落在另一个零件上、面与面贴合、销钉对位），但"把图案从父代复制到副本"
  这一步在物理上做了简化——画面上是"副本压到父代上"，图案随之转移。
* 切点被限制在 1–5，理由见上（尾段要留给传送梭）。
* 图中文字只有表盘刻度（0–8）、计数器（两位数字）与名牌板上的三道短线；
  其余说明都在卡片四角、图例和图注里。
